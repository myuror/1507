# Симулятор: Изменение плоскости орбиты

**Цель проекта:** Исследование изменения плоскости орбиты космического аппарата при разных аргументах широты (точках выполнения манёвра). Симулятор наглядно демонстрирует эффективность приложения импульса в узлах орбиты по сравнению с другими её участками.

## Правила и критерии успеха
* **Задача:** Изменить наклонение орбиты ($\Delta i$) на заданный угол, выбрав оптимальную точку для манёвра.
* **Успех миссии:** Затраты характеристической скорости ($\Delta V$) не должны превышать критический бюджет топлива (**220 м/с**). Наилучший результат достигается при манёвре строго в узлах орбиты ($0^\circ$ или $180^\circ$).
* **Крах миссии:** Если манёвр совершается в экстремальных точках ($90^\circ$ или $270^\circ$), затраты топлива резко возрастают. При превышении лимита система сообщает о нехватке топлива и предлагает начать заново.

## Управление
* **На компьютере и телефоне:** Корректировка параметров (угол манёвра и целевое наклонение) осуществляется с помощью адаптивных ползунков. Запуск анимации и сброс состояния производятся кнопками «Запустить симуляцию» и «Сбросить».

## Ограничения и допущения
* Модель является учебной и упрощённой.
* Расчёты производятся для круговых орбит без учёта влияния атмосферы и гравитационных аномалий.
* В формулу расчёта $\Delta V$ заложен коэффициент потерь за смещение от линии узлов.
